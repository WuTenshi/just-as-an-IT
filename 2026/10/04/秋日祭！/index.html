秋日祭！

2026-10-04

约定在国庆的秋日祭合作开始了
意料之中，站长和z站人员还是产生了矛盾，从此一蹶不振
一个月前就归我接手了
有小琦和繁星的创作支持以及艺术评估，页面设计不成问题
活动页面，创作相对容易，不过技术力有限，很难做得精致

活动仅有四个稿件，缺人手是最大的痛点

技术上，通过搓出一个初版html页面，导入png，再通过js实时渲染
插入大量的地址和动态效果实现了页面美化
由于是纯静态页面，直接更改Node.js项目的nginx配置秋日祭路径即可
只添了几行，非常简单的操作
location = /autumn-festival {
return 301 /autumn-festival/;
}
location ^~ /autumn-festival/ {
alias /www/wwwroot/nuomill-autumn-festival/;
}

还有一个友情赞助，由群友 藤原妹红 做的盲文点阵项目，我将它部署到了秋日祭页面
同样是纯静态页面，只需要修改nginx配置即可
location = /braille-web {
return 301 /braille-web/;
}
location ^~ /braille-web/ {
alias /www/wwwroot/braille-web/;
index index.html;
}

合作视频最终上传到了b站，播放量惨不忍睹
小站难活，的确如此吧
