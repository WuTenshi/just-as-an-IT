经济系统&小窝系统

2026-09-01 · #开发

我们的魔丸站长初见端倪了
提出了一个令人无语的方案

仅仅针对此段方案，站长的画像就很明显了
DeepSeek如此总结道：

我们一般认为AI接管大脑是一种脑残行为
严重脱离技术落地、缺乏合规底线，且极度依赖AI“画大饼”的创意型产品策划
指望一个没有备案的不正规网站，拉一大堆人去替她打工赚钱
即便如此，AI也给我带来了不少的便利
删删改改，让我对java项目有了初步的认识
面向对象式的程序设计，分为以下几个部分
src/main/java/com/example/project/
├── Application.java # 启动类
├── controller/ # 控制器
├── service/ # 业务接口
│ └── impl/ # 业务实现
├── dao/ 或 repository/ # 数据访问
├── entity/ 或 model/ # 数据库实体
├── dto/ 或 vo/ # 传输/视图对象
├── config/ # 配置类
├── util/ # 工具类
├── exception/ # 异常处理
└── interceptor/ # 拦截器
src/main/resources/
├── application.yml # 主配置
└── mapper/ # MyBatis XML（如使用）

也仅仅是框架了，真正做出来的东西只能通过localhost显示
根本没人会去做前端页面

至于小窝系统，我只能说，已经做好的项目，连源码都没有，开发什么？
